Entry for [The Robot Vacuum's Best Excuse](https://make.fun/c/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214?ref=h379tqrk) on make.fun.

`main.py` writes one one-line excuse from a robot vacuum to `/output/entry.txt` (97 characters, within the 1–140 gate). Angle 2: the cat sits on the vacuum's lidar and declares the missed spot a no-clean zone — the vacuum obeys, because the cat is its boss now.

Run it:

```
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Stdlib only, no network, no secrets.
